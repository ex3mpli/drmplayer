# DRMPlayer

A DASH & M3U8 player built with Shaka Player. Supports ClearKey (multiple keys), Widevine, playlists, themes, and keyboard shortcuts.

![Version](https://img.shields.io/badge/version-0.0.2-blue)

## Demo

[https://ex3mpli.github.io/drmplayer/](https://drmplayer.ex3mpli.workers.dev/)

## Features

- DASH & M3U8
- Playlist Manager
- Light & Dark Theme
- Keyboard Shortcuts
- PiP | Fullscreen | Volume Controls

## Usage

Open `index.html` in a modern browser. Paste a DASH MPD URL and click Play. Use the playlist icon to manage saved channels.

## Shortcuts

`Space` play/pause · `F` fullscreen · `M` mute · `←/→` seek · `↑/↓` volume · `Esc` close modal · `Enter` save in edit modal
